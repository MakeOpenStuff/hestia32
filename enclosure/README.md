# Enclosure

This folder contains the printable enclosure parts for the Hestia32 device.
Use eight M2xL4xOD3.2 mm threaded inserts for screen and PCB.

## Contents
- Base enclosure: mounts to the wall and houses the main PCB
- Cover enclosure: snaps onto the base and holds the display
